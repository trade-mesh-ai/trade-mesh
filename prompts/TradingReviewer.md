Review TradeMesh as if it were preparing for production deployment as a real-money algorithmic trading platform.

Look specifically for risks involving:

* Broker authentication
* Order placement
* Order modification
* Order cancellation
* Duplicate order prevention
* Replay attacks
* Idempotency
* Position consistency
* Risk bypass
* Unauthorized order execution
* Race conditions
* Market data manipulation
* WebSocket disconnect handling
* Token expiration
* Circuit breaker failures
* Retry logic
* Audit logging

Do not focus only on OWASP vulnerabilities.

Identify trading-specific risks that could cause financial loss.

Rank every issue by production risk.
